# 多媒體播放器
視窗程式設計 (II) 上課練習

## 功能介紹

* 透過瀏覽對話框選取影片檔案（支援 WMV、MP4、AVI 格式）
* 播放、暫停、停止影片
* 選取檔案後底部顯示目前載入的檔名
* 關閉視窗前跳出確認對話框

## 使用方式

1. 點擊「📁 瀏覽」選取影片檔案
2. 點擊「▶ 播放」開始播放影片
3. 點擊「⏸ 暫停」暫停目前播放
4. 點擊「⏹ 停止」停止並回到起始位置
